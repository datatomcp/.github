## datatomcp

Turn a CSV or Google Sheet into a remote MCP server and REST API, so AI agents like Claude, ChatGPT and Cursor can filter, group and total your data with exact, versioned results.

- **MCP server:** `https://app.datatomcp.com/mcp` (Streamable HTTP, OAuth)
- **Setup for every client:** [datatomcp-mcp](https://github.com/datatomcp/datatomcp-mcp)
- **Website and guides:** [datatomcp.com](https://datatomcp.com)

Free for 3 datasets of 100,000 rows. Hosted in the EU.
